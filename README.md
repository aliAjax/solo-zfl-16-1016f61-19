# 活字排版工坊

一个纯前端本地应用（打开 `index.html` 即用，数据保存在浏览器 localStorage）。

## 排版工作台

- 维护字模库（字、风格、字号、数量、旧化程度），在网格版面落字或拖拽排版
- 自动核对字模用量，超量标红；保存草稿、导出 PNG 预览图

## 纸张与开料（新增）

顶部切换到「纸张与开料」标签。

**纸张库存**

- 按 尺寸（统一归一为宽≥高）/ 克重 / 纹向 / 数量 分组入库，同规格自动合并
- 裁剪下来的边料以虚线卡片单独成组入库，自动排料时优先复用边料，再用原纸
- 每组显示：在库、已预留、可用

**开料单**

填写成品尺寸、数量、出血（每边）、损耗（%）、克重，以及是否要求顺纹（纹向平行成品长边），系统自动计算：

- 含出血的排料尺寸、每张可出份数（两种朝向取优，勾顺纹时只保留顺纹排法）
- 含损耗的应出份数、建议领用张数、每张纸裁出的边料清单（小于 10mm 的碎边丢弃）
- 可手工增删领用纸组、调整每张数；实时重算可出份数与缺口，**超过可用库存即标红并禁止保存/开工**
- 缺量明确列出份数，可先「保存并预留」（待开工），但「开工」被拦住，备料补足后才能开工

**预留与排期**

- 看板四列：待开工 → 裁剪中 → 完成 / 取消
- 待开工/裁剪中的单据先预留纸张，其他单据的自动规划与手工领用都会扣除这部分预留，不能重复占用
- 取消：释放全部未用预留，不动实物库存
- 完成：裁剪中点「完成」进入**完工结算**，可逐组填写**实际领用张数**（默认带出计划数）；确认后按实际数量扣库存、按实际数量回报边料，实际没用完的预留自动释放；结算时同样不得超用。同一单据重复完工不会重复扣减
- 刷新页面后库存、预留、排期、边料从 localStorage 重建并保持一致
